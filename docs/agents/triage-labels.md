# Triage Labels

Use this one-to-one GitHub label mapping:

| Workflow state | GitHub label |
|---|---|
| Unclassified incoming work | `needs-triage` |
| Waiting for required information | `needs-info` |
| Fully specified and implementable | `ready-for-agent` |
| Requires a human-only action or decision | `ready-for-human` |
| Intentionally rejected or closed without implementation | `wontfix` |

Do not create synonymous labels.
